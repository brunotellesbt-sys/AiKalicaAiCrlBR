LeafGreen Journey

Jogue a versão com rotas de Surf entre Kanto e as ilhas Sevii, Birth Island e Navel Rock.

Hoenn e a história de Emerald ainda estão em desenvolvimento e não fazem parte desta versão.

Controles: setas para mover, X = A, Z = B, Enter = Start. No celular, use os controles na tela.

Comece um jogo novo nesta versão. Use o menu do emulador para exportar seus saves; os dados guardados pelo navegador podem ser apagados junto com os dados do site.

Código e ROM no GitHub · Emulador: EmulatorJS 4.2.3
