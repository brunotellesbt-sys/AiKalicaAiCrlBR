# Registro de erros

Antes de alterar terreno, água, pontes, encostas ou objetos compostos, consulte
[erros dos nove vídeos de 28/10/2026](2026-10-28-videos-surf-tiles.txt) e
[o guia de ajustes GBA](../docs/AJUSTES-GBA.txt).

Registre local, reprodução, causa, solução e prova da ROM final. Diferencie
defeito confirmado, aparência nativa e verificação pendente. Não declare uma
correção validada apenas porque a imagem do mapa parece correta.
