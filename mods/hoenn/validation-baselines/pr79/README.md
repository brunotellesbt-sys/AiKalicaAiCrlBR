# Validação histórica do PR #79

Este diretório preserva a ROM-base comprimida, o manifesto e as evidências da versão anterior. Os hashes e os quatro registros de edição permitem reconstruir os bytes exatos testados, sem redistribuir quatro cópias adicionais.

As rodadas de torneio e de mecânicas daqui **não foram repetidas nas ROMs da atualização costeira**. As evidências novas de níveis, portos, atores, mapa e encontros especiais estão em `coastal-update-validation/`. O verificador distingue as duas versões e rejeita evidências antigas apresentadas como resultados atuais.
